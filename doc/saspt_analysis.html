State-Array SPT (saSPT)

The saSPT analysis ports the state-array SPT method of Heckert, Dahal, Tjian & Darzacq (eLife 2022) into the smt-pipeline. Instead of fitting a few discrete diffusive states (as in pEM), saSPT places a dense grid over (D, σloc) and returns a variational-Bayes posterior occupancy over that grid — i.e. a non-parametric estimate of the joint distribution of diffusion coefficient and localization precision.

The implementation lives in utils/saSPT/ and is wired into TrajectoryCollection via four methods: getStateArrayPosterior, getStateArrayPosteriorBootstrap, plotStateArrayPosteriorD, and plotStateArrayPosterior2D. Two-condition comparisons are done by utils/compareStateArrayPosteriors.m.

When to use saSPT vs. pEM vs. fBM

MethodUse whenReturns
getBayesianDiffusivity (pEM) You want a small number of discrete diffusive states with fractions. K state means + populations, BIC-selected K.
getStateArrayPosterior (saSPT) You want a non-parametric, model-comparison-friendly view of the diffusivity distribution — and you do not want to commit to a state count. Posterior occupancy over a 2-D (D, σloc) grid; marginal posterior over D.
getFBMParameters (fBM) You care about the anomalous exponent α (sub-/superdiffusion) of the population. K, α, σ with profile-likelihood or MCMC CIs.
Track type: saSPT operates on culled tracks. Do not use relative tracks — the saSPT model assumes the observed displacements are Brownian + localization noise, which is violated once cell motion has been subtracted via the spanning forest.

getStateArrayPosterior

results = tc.getStateArrayPosterior() results = tc.getStateArrayPosterior('Condition','Control', ... 'SplitSize',7, ... 'D', logspace(-3,log10(20),64), ... 'LocError', linspace(0.01,0.1,24), ... 'FrameInterval',0.01, ... 'ExposureTime', 0.005)

Parameters

ParameterDefaultDescription
Condition[]Restrict to one or more conditions (string, cellstr, or string array). Empty = full collection.
SplitSize7Maximum sub-track length M (frames). Tracks are first cut at every frame discontinuity (gap-aware), then each gap-free run is broken into non-overlapping chunks of length 3 ≤ L ≤ M.
Dlogspace(log10(1e-3), log10(20), 64)1-D diffusion-coefficient grid (µm² s⁻¹). Log-spaced spanning ~10⁻³ to 20 µm²/s covers chromatin-bound through freely-diffusing nuclear proteins.
LocErrorlinspace(0.01, 0.1, 24)Localization-precision grid (µm). Marginalizing over σloc rather than fixing it removes a common source of bias in fast-diffusion estimates.
FrameIntervalautoSampling interval (s). Defaults to the wrappers' stored FrameInterval for the requested condition.
ExposureTime= FrameIntervalCamera exposure (s). Used for motion-blur correction. Set to 0 to recover the static (no-blur) covariance.
ShutterR1/6Shutter coefficient (Berglund 2010). 1/6 is correct for uniform box exposure.

Algorithm internals

  1. saSPT_splitTracks — gap-aware splitting into M-frame sub-tracks. Any frame discontinuity (diff(frame) ≠ 1) breaks the track before chunking, so no sub-track straddles a gap.
  2. saSPT_calc_likelihood — for each sub-track evaluates the multivariate Gaussian log-likelihood of the step vector under regular Brownian motion + isotropic Gaussian localization noise at every (D, σloc) grid point. The x and y dimensions are treated as independent, so log P(Δx, Δy) = log P(Δx) + log P(Δy) (the 1-D normalizer is counted twice — this is the corrected version of the original Heckert calc_likelihood.m).
  3. Motion-blur covariance (Berglund 2010 / Heckert 2021): 
    var(Δx)        = 2(D·dt + σ²) − 4·R·D·t_exp
cov(Δx, Δx_+1) = −σ² + 2·R·D·t_exp
  4. saSPT_compute_posterior — variational-Bayes EM (Bishop PRML Ch. 10) with a symmetric Dirichlet prior (α = 1 / (LD · LL)) over the grid. Iterates up to 100 times.

Stored in tc.SAStateResults. Key fields:

getStateArrayPosteriorBootstrap

Cluster-bootstrap (or jackknife) CIs on the marginal D posterior. Resamples FOVs (or cells / equal-sized chunks) with replacement, re-runs the cheap posterior update, and returns per-D-bin percentile intervals. The expensive log-likelihood evaluation is done once across all sub-tracks and re-sliced inside the bootstrap loop, so each iteration is nearly free.

results = tc.getStateArrayPosteriorBootstrap() results = tc.getStateArrayPosteriorBootstrap('Condition','Control', ... 'NumBootstraps',200, ... 'Mode','cluster', ... 'ClusterBy','fov', ... 'Parallel',true)

Parameters

ParameterDefaultDescription
Condition[]Same semantics as in getStateArrayPosterior.
SplitSize, D, LocError, FrameInterval, ExposureTime, ShutterRsee abovePass-through to saSPT_bootstrap_CI. Match the values used by the previous getStateArrayPosterior call so the cached point estimate and the bootstrap CI live on the same grid.
NumBootstraps200Number of resampling iterations.
AlphaCI0.05Percentile-CI level (default 95% CI).
Mode'cluster''cluster' = bootstrap with replacement; 'jackknife' = leave-one-cluster-out SE.
ClusterBy'fov'Resampling unit: 'fov' (default), 'cell' (one cluster per (FOV, ROI) — needs TC input + culled tracks), or 'chunk' (equal-sized random chunks of ChunkSize sub-tracks).
ChunkSize5000Sub-tracks per chunk in ClusterBy='chunk' mode.
MinSubtracksPerCluster50 for 'cell', 0 otherwiseDrop sparse clusters before resampling. Ignored in chunk mode.
Seed[]RNG seed.
ParallelfalseUse parfor for the bootstrap loop; auto-launches a parpool if none is open.
Which clustering unit?
  • 'fov' — default; captures FOV-to-FOV biological variability. Use when FOVs are roughly comparable in track count.
  • 'cell' — captures cell-to-cell variability inside FOVs. Use when cells are similarly sized; needs ROI metadata on the wrappers.
  • 'chunk' — equal-sized random chunks. Use when FOVs/cells are very imbalanced (e.g. 1 vs. 1000 tracks). The CI then reflects variance of the variational posterior, not biological clustering — interpret accordingly and don't claim it as a between-cell error bar.

Plotting

plotStateArrayPosteriorD

fig = tc.plotStateArrayPosteriorD() fig = tc.plotStateArrayPosteriorD('Bootstrap', bootResults, ... 'Color', [0 0.4 0.8], 'Title', 'ER 100 kPa')

Line plot of the marginal posterior over D. If a bootstrap struct is supplied (or the most recent one is cached on the object), the percentile CI is shaded and the bootstrap mean is drawn dashed. The plotter validates that the bootstrap was computed on the same D, SplitSize, FrameInterval, ExposureTime, ShutterR, and Condition as the cached posterior, and errors otherwise — pass 'Bootstrap' explicitly or rerun the bootstrap if you hit that guard.

plotStateArrayPosterior2D

fig = tc.plotStateArrayPosterior2D('Title', 'ER 100 kPa')

pcolor of the full joint posterior over (D, σloc). Useful as a diagnostic — a posterior that piles up at the σloc grid boundary indicates the grid is too narrow.

compareStateArrayPosteriors

Quantitative two-condition comparison of the marginal D posteriors. Reports:

  • Wasserstein-1 distance on log10(D) (in decades) — a single-number "how different are these two distributions" summary.
  • Jensen-Shannon divergence (and its square-root, a true metric).
  • Slow/fast fraction differences — occupancy below SlowCutoff and above FastCutoff, with paired-bootstrap CIs.
  • Peak shift — log10(peakD_B / peakD_A).
out = compareStateArrayPosteriors(boot_A, boot_B, ... 'SlowCutoff', 0.05, 'FastCutoff', 0.5, 'AlphaCI', 0.05, 'Seed', 42)

Inputs

boot_A and boot_B are the structs returned by getStateArrayPosteriorBootstrap for each condition. The D grids must match. CIs are computed by pairing bootstrap iterations across conditions (random unmatched pairing) and re-evaluating each metric per pair, so differences carry a tighter CI than would be obtained by subtracting independent CIs.

Output

Each metric field is a struct with .point (full-pool point estimate) and .CI = [lo hi] (percentile CI from the bootstrap pairing). Recommended report: Wasserstein-1 plus the bound-fraction difference, both with their CIs.

End-to-end example

run('setup_path.m');

% --- Load both conditions into one collection ----------------------------
tc = TrajectoryCollection();
tc.ReadParams('experiment.toml');
tc.loadFromFiles(dir('data/soft/*.csv'),  [], [], 'ER_1kPa');
tc.loadFromFiles(dir('data/stiff/*.csv'), [], [], 'ER_100kPa');

% --- Point posteriors (one per condition) --------------------------------
res_soft  = tc.getStateArrayPosterior('Condition','ER_1kPa');
res_stiff = tc.getStateArrayPosterior('Condition','ER_100kPa');

% --- FOV-cluster bootstrap CIs (matched grid) ----------------------------
boot_soft = tc.getStateArrayPosteriorBootstrap('Condition','ER_1kPa', ...
                'NumBootstraps',200, 'Parallel',true);
boot_stiff = tc.getStateArrayPosteriorBootstrap('Condition','ER_100kPa', ...
                'NumBootstraps',200, 'Parallel',true);

% --- Plot ----------------------------------------------------------------
tc.plotStateArrayPosteriorD('Bootstrap', boot_soft,  ...
    'Color',[0.2 0.6 1.0], 'Title','ER 1 kPa');
tc.plotStateArrayPosteriorD('Bootstrap', boot_stiff, ...
    'Color',[1.0 0.4 0.2], 'Title','ER 100 kPa');

% --- Two-condition comparison with paired-bootstrap CIs ------------------
cmp = compareStateArrayPosteriors(boot_soft, boot_stiff, ...
        'SlowCutoff',0.05, 'FastCutoff',0.5);
fprintf('W1 (log10 D) = %.3f  [%.3f, %.3f] decades\n', ...
        cmp.W1_log10D.point, cmp.W1_log10D.CI(1), cmp.W1_log10D.CI(2));
fprintf('slow frac (stiff − soft) = %+.3f  [%+.3f, %+.3f]\n', ...
        -cmp.slowFrac_diff.point, ...        % B − A reported as stiff − soft
        -cmp.slowFrac_diff.CI(2), -cmp.slowFrac_diff.CI(1));

Notes & caveats

  • Brownian assumption. saSPT models each sub-track as Brownian + Gaussian noise. Anomalous (fBM) motion will be projected onto the closest Brownian state — read the marginal as an effective diffusivity distribution, not a kinetic decomposition. If you care about α, use getFBMParameters or getFBMByPEMState instead.
  • Grid coverage. If the 2-D posterior piles up at the boundary of either grid, widen it. Default ranges (10⁻³ to 20 µm²/s; 0.01 to 0.1 µm) cover typical mammalian-nucleus SMT but are not universal.
  • SplitSize tradeoff. Larger M (e.g. 12-20) yields a sharper posterior for slow states but discards more short tracks; smaller M (default 7) keeps more sub-tracks at the cost of breadth. saSPT is not very sensitive to M in the 5-12 range for nuclear-protein SMT.
  • Motion blur matters. For stroboscopic acquisition (your acquisition memo: 10 ms exposure / 200 ms interval ⇒ exposure_fraction = 0.05) the blur correction is small but non-zero. For continuous-exposure data the correction is essential and ignoring it will inflate apparent D.
  • Bootstrap stale-cache guard. plotStateArrayPosteriorD compares the bootstrap struct's grid/options against the cached SAStateResults and errors on mismatch. This is intentional — silently overlaying a CI computed at different exposure/grid would be a quiet bug.
